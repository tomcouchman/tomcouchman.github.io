Featured / Python

HomeSOC Log Analyzer

A defensive-security utility that reads SSH authentication logs, groups failed-login events by source IP and assigns severity using clear thresholds.

Problem
Repeated login failures are difficult to assess quickly in raw logs.
Method
Parse events, group by source, count failures and apply explicit rules.
Output
A concise severity-based incident summary.
Demonstrates
Python, log analysis, detection logic, reporting and Git.
Open repository ↗ Use interactive demo

Limitations / honest scope

What it does not claim to be

HomeSOC is a foundation project, not a production SIEM or machine-learning detector. Its value is in showing a transparent workflow and a clear explanation of why an event is classified.
